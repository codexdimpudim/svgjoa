About joaosbreeze

An independent fork maintained by codexdimpudim, based on Breeze. The original app credits x8rr as its creator.

Browse the fork and its changes or download the repository. Original credits in Settings remain intact, including the projects and services used by Breeze.

The upstream snapshot contains bundled JavaScript and WebAssembly, but no original app source tree or build instructions. This repository makes available every file received plus this fork's modifications. That does not establish that the complete Corresponding Source required by the AGPL is present. The preferred editable sources, dependency notices and reproducible build information still need to be obtained from upstream.

What changed on October 27, 2026

  • Uses the owner-selected name joaosbreeze while preserving the existing layout and colors.
  • Removes the original Google Analytics integration, remote error reporting and click-triggered advertising.
  • Uses ordinary readable text by default and removes the unrelated classroom launch screen and adds visible ownership, source and license links to both entry points.
  • Serves the interactive SVG through jsDelivr and uses GitHub Pages as an entry address and for these notices.

Features and outside services

GitHub stores this site's files, and jsDelivr serves the interactive SVG. The GitHub Pages entry address redirects to that CDN version. Proxy browsing, game delivery, movie/TV and manga features use outside services inherited from Breeze; they can fail or change independently of this fork. GitHub Pages cannot run those backend services.

Verification on October 27, 2026: the homepage, movie catalog and manga catalog loaded through jsDelivr. The inherited API explicitly permits the jsDelivr origin, while direct API access from the GitHub Pages origin is not permitted. Use the CDN version for the intended functionality. The services remain operated by upstream, so availability can change.

Using network features sends the requested searches, destinations or content requests to their service operators. Google Fonts, game providers and content services may receive network requests. This fork removes the inherited analytics and error reporting; it does not control data practices inside external sites or embedded content.

Local appearance settings and favorites are saved in your browser. Third-party games, media, fonts and libraries may carry their own terms; the repository license does not by itself establish permission to redistribute every asset or content item.
